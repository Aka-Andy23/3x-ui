# Руководство пользователя Happ

Администратор выдаёт одну персональную HTTPS-ссылку. Она содержит только ваши
разрешённые inbound, выбранные узлы и назначенные внешние подключения.

## Импорт

1. Откройте добавление подписки в Happ Android, iOS или Desktop.
2. Вставьте ссылку либо отсканируйте QR-код из карточки клиента.
3. Обновите подписку и выберите подключение.
4. Если включён автовыбор, разрешите Happ выполнить ping при открытии.

Не пересылайте ссылку: `subscription ID` даёт доступ к вашей конфигурации.
При утечке обратитесь к администратору для перевыпуска.

## Обновление

Happ использует ETag, поэтому неизменившаяся подписка может отвечать `304`.
После изменения inbound, прямых доменов или внешнего источника обновите
подписку. Администратор также может выполнить принудительную регенерацию.

## Статусы и ошибки

- «Действует» — JSON создан и прошёл валидацию.
- «Частично» — локальные подключения работают, но один внешний источник
  вернул ошибку; используется last-known-good.
- «Нет доступных подключений» — нет включённых и доступных кандидатов.
- Ошибка Provider ID — автоматический режим не включится, пока администратор
  не задаст корректный восьмисимвольный ID.

Ping измеряет ваше устройство. Задержка панели до узла — отдельная
диагностическая величина и не определяет выбор Happ.
